# NaviTest R9 – verze 0.3

Novinky:
- Vlastní mapa z OpenStreetMap (OpenFreeMap, bez klíče) kreslená v telefonu – funguje i se zamčeným
  telefonem, zoom joystickem reaguje hned. Dlaždice se ukládají do telefonu a podél trasy se předstahují.
- Šipka a vzdálenost do další odbočky přímo v obrázku (levý horní roh).
- Obrázek vždy typ 0 → přístrojovka bez levého sloupce.
- Varování ve formátu jako StreetCross: radar pevný / úsekový / na červenou / mobilní, škola, hranice, rychlost.
- Oprava posunuté Apple mapy (měřítko 3×). Apple mapa zůstává jen jako volba pro odemčený telefon.

Mapová data © přispěvatelé OpenStreetMap, dlaždice OpenFreeMap, © OpenMapTiles.
