# NaviTest R9 – version 0.9

Rider assistance (OpenStreetMap via Overpass, downloaded along the route, no key)
- Speed cameras (fixed / red light), average speed sections, school zones → native dashboard warnings
  with distance, updated while approaching and cleared after passing.
- Speed limits along the route → dashboard limit sign; speeding alert with tolerance (+ km/h).
- Alert sound per type: voice or one of 10 generated tones; separate alert volume.
- Speed from the bike (service 65) when connected, otherwise GPS.

Waypoints and saved routes
- "Add stop" on a place card, route planner (reorder, delete), navigate through all stops.
- Garmin waypoint icons (3/4/5), remaining waypoint count to the dashboard, "skip waypoint" from the bike,
  rerouting continues through the remaining stops, red pins on the bike map.
- Save routes by name, load them later (recalculated from the current position).

Fixes
- Search results close after starting navigation.
- Older stored map tiles are used when there is no internet.
