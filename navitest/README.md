# NaviTest R9 – verze 0.2

Novinky: skutečná navigace přes Apple Mapy (hledání cíle, trasa, přepočet při sjetí z trasy),
Apple mapa nebo vlastní mapa v obrázku, přepínač typu obrázku (0/3/1) a šířky, test varování
(radar, úsekové měření, rychlost, škola), zoom joystickem mění měřítko mapy, STOP trasy z motorky.

## Co otestovat
1. Na zastavené motorce: Navigace → Simulace. V „Mapa v motorce“ přepínat typ obrázku 0 / 3 / 1
   a sledovat, jestli se v levém sloupci přístrojovky objeví šipka a vzdálenost.
2. Šířka 560/600/640 – jestli přístrojovka obraz roztáhne, ořízne, nebo odmítne (appka se sama vrátí na 480).
3. Varování: tlačítka Radar 50 / Úsekové / Rychlost / Škola – vyfotit, co ukáže přístrojovka.
4. Skutečná jízda: zadat cíl, Hledat, vybrat, zamknout telefon, jet. Schválně jednou sjet z trasy.
5. Poslat exportovaný log + fotky.
